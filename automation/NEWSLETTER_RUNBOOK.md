Only update issue date, factual headline, named subjects, supporting imagery, short teaser and captions. - User-approved November 13 post is recorded at `data/newsletter-2026-11-13-publication.json`. All future runs must check their date-specific equivalent and Buffer history first. Do not add newsletter entries to the separate evergreen publication ledger.

## Stop switch

Setting GitHub repository variable `PUBLISHING_ENABLED=false` stops future creation in both the newsletter heartbeat and evergreen workflow. Pausing the Codex heartbeat alone stops newsletter creation only. Already queued evergreen posts still publish unless the Buffer channels are separately paused.
